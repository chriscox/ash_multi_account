# Ash Multi Account Demo App

A complete Phoenix application demonstrating multi-account linking and switching using the `ash_multi_account` library.

## What This Demo Does

This app lets you register multiple user accounts and link them together in a single browser session. Once linked, you can switch between accounts without re-authenticating — like Google's account switcher.

The demo exercises every integration point:
- **AshAuthentication** password strategy for registration and sign-in
- **AshMultiAccount** extensions on User and LinkedAccount resources
- **Controller** for link/switch actions with session management
- **LiveView hook** that resolves `@current_user` and `@primary_user` on every mount
- **Account switcher component** in a dropdown menu with slot-based rendering
- **Session token plug** for automatic token management

## Stack

- Phoenix 1.7 + LiveView 1.0
- Ash 3.x + AshAuthentication 4.x
- ETS data layer (no external dependencies)
- DaisyUI + Tailwind CSS for styling

> **Note:** Data is stored in-memory via ETS and resets on server restart. This is by design — the demo is meant for exploring the library, not for production use.

## Setup

```bash
cd example/demo
mix setup                  # install deps, build assets
mix phx.server             # start at http://localhost:4000
```

## Walkthrough

1. **Register two users** — use different email addresses
2. **Sign in as User A** — you're in single-account mode, the user menu shows one entry
3. **Click "Add another account"** in the user menu dropdown — redirects to sign-in
4. **Sign in as User B** — User B is automatically linked to User A's session. Both accounts now appear in the dropdown.
5. **Click User A's name** in the dropdown — the session switches to User A without re-authenticating
6. **Sign out and sign in fresh** — links are session-scoped, so you're back to single-account mode

## Key Files

| File | Purpose |
|------|---------|
| `lib/demo/accounts/user.ex` | User resource with `AshMultiAccount` extension |
| `lib/demo/accounts/linked_account.ex` | LinkedAccount resource — schema generated by transformer |
| `lib/demo_web/controllers/auth_controller.ex` | Auth callbacks with `put_user_id` for multi-account |
| `lib/demo_web/controllers/multi_account_controller.ex` | Link/switch controller actions |
| `lib/demo_web/router.ex` | Routes, plug, and LiveView hook configuration |
| `lib/demo_web/live/home_live.ex` | Main page with account switcher dropdown |
